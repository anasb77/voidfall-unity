1. **Two agents work this repo concurrently** — one on game content (roulette
   feature in `Content/` + `UI/Views/RouletteView.cs`), one on structure.
   **Stage commits by explicit file path, never `git add -A`.**
2. The PlayMode golden-master test is the behavior contract. Structural
   refactors must leave its pinned hash unchanged:
   `15261090775683682834`. Intentional gameplay changes regenerate the hash
   in a separate commit with an explanation.
3. Content agents and structure agents stay out of each other's files.
