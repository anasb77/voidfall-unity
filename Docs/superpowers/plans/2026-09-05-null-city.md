# Null City Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Integrate the approved Null City arena, exclusive roster and Motherload into the active Unity game.
**Architecture:** Extend VoidFallGameRuntime partials and existing GameSim pools. Engine-free content/rules own stable definitions; prepared Addressables plates own visual assets. Existing objective and journey code owns completion.
**Tech Stack:** Unity 6000.5.7f1, C#, URP, Addressables, offline Node canvas authoring, NUnit.
**Spec:** Docs/Design/NullCity-Approved.md

## Global constraints

- Start runs in Abyss; stable city ID is `null-city`.
- Do not change generated ContentCatalog.Generated.cs or serialized IDs.
- Preserve unrelated pending route/roulette work and pool iteration/RNG contracts.
- No runtime full-screen painting or per-entity MonoBehaviours.
- Unity CLI execution is owned by the root agent to avoid competing Editors.
